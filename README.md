# 🍽️ Crave Buddy – Online Food Delivery Website

Crave Buddy is a modern full-stack online food delivery web application designed to make food ordering easy, convenient, and personalized.

Built using React, TypeScript, Tailwind CSS, Node.js, Express.js, and PostgreSQL, Crave Buddy allows users to explore restaurants, browse delicious food items, manage their shopping cart, and place food orders.

## 🌟 Key Features

- **Restaurant Browsing:** Explore different restaurants and their food menus.
- **Food Discovery:** Browse a variety of food items with images and details.
- **Smart Cart:** Add food items, update quantities, and manage multiple orders.
- **Build Your Own Thali:** Create a personalized thali by selecting different dishes from multiple restaurants.
- **Drag and Drop Ordering:** Easily add selected food items to your cart.
- **Order Management:** View orders and track order details.
- **Food Details:** Explore food descriptions and ingredients.
- **Checkout:** Review your cart and total bill before placing an order.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/iamsonu-stack/Crave-buddy.git
```

### 2. Navigate to Project Folder

```bash
cd Crave-buddy
```

### 3. Install Dependencies

Install the frontend and backend dependencies:

```bash
cd frontend
npm install
```

```bash
cd ../backend
npm install
```

### 4. Configure Environment Variables

Create `.env` files according to your backend and frontend configuration.

Add your PostgreSQL database connection details and other required environment variables.

Never upload secret keys or database passwords to GitHub.

### 5. Run the Application

Start the backend and frontend using the development scripts defined in their respective `package.json` files.
